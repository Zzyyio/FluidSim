# 二维 GPU Stable Fluids

从本目录启动：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 http://localhost:8000 。无需构建、npm 或付费软件；不要直接双击 HTML（GLSL 通过 fetch 加载）。需要浏览器支持 WebGL2、EXT_color_buffer_float。

拖动鼠标或触屏注入速度和颜料。默认按局部速度大小显示：固定范围从零速度的蓝色，经青、绿、黄，到上限速度的红色；超过上限保持红色。颜色上限单位为模拟网格格/秒，可以调整；也可切换颜料显示。清空按钮重置模拟。

## 文件

- index.html：页面结构与入口。
- styles.css：面板、控件、响应式布局和切换动画。
- ui.js：面板收起、显示模式和色相选择交互。
- fluid.js：WebGL2 宿主、浮点 framebuffer、ping-pong、指针输入和逐帧调度。
- fluid.glsl：通过 mode 选择平流、注入、散度、Jacobi、投影、边界和显示 Pass。

## 流程

速度半拉格朗日平流 → 外力注入 → 封闭边界 → 散度 → 60 次 Jacobi 压力迭代 → 减去压力梯度 → 染料平流 → 显示。

时间步最大 1/30 秒，速度单位为格/秒。平流使用手动双线性插值，无需浮点线性过滤扩展。压力满足 Laplacian(p)=div(v)，Jacobi 使用有效邻居数实现零法向压力梯度。速度分量视为右/上面通量，散度使用后向差分，压力梯度使用前向差分，使投影算子匹配；边界外法向通量为零。平流对存储速度做近似同位置采样，适合视觉演示，并非严格 MAC 求解器。

速度、颜料、压力分别拥有两张 RGBA16F 纹理，读写分离；散度独立一张。模拟长边 256 格，显示匹配设备像素比（最多 2）。窗口尺寸变化会释放旧纹理、重新分配并清空状态。上下文丢失会提示刷新。

这是含可调隐式粘性扩散的 Stable Fluids 视觉实现，包含数值耗散和指数衰减。有限次压力迭代只能近似消除散度，不保证严格不可压缩。单 Image Pass 无法调度本实现所需的每帧压力迭代，因此使用独立宿主；原 Shader Studio 文件保持不变。

## 检查

`node --check fluid.js` 检查 JavaScript 语法。运行时检查 shader 编译、链接、浮点附件完整性，错误显示于页面。

手动验收：拖动确认速度变红，停止后逐渐衰减；切换颜料确认输运；清空；改变窗口尺寸；在四周拖动确认无穿越边界或异常闪烁。

## 可调参数

- 红色速度阈值：固定色阶上限，仅影响显示。
- 粘度：0–100 基准格²/秒；对速度做隐式扩散，40 次 Jacobi 求解，0 时跳过。固定右端速度使用独立纹理保存，再进行不可压缩投影。
- 画笔半径：1–30 基准格，高斯注入范围。
- 注入力度：0–4 倍，控制拖动推动速度的强度。
- 颜料注入量：0–60/秒；按住持续注入，按时间步计量，不依赖指针事件数量。
- 颜料颜色：仅影响新注入的 RGB 颜料。选择颜料显示查看，速度配色仍为蓝→青→绿→黄→红。

拖动路径分段注入以减少间断；颜料采用加色混合和曝光映射，浓度较高时会变亮。

## 衰减与涡旋

速度衰减和颜料消散范围为 0–3 /秒，分别按 exp(-参数 × dt) 衰减，默认保持原来的 0.12 与 0.08。0 关闭显式衰减，但平流仍有数值耗散。颜料消散仅在颜料模式显示，切换显示不会停止模拟。

涡旋增强范围 0–10，默认为 0。新增 curl 纹理与两个 Pass：计算旋度，再沿旋度绝对值梯度施加 confinement 力，随后执行压力投影。梯度为零时安全处理；附加加速度限制在 1000 格/秒²。它是视觉增强，不是物理粘度。

## 时间与质量

- 时间倍率：0.1–2×，默认 1。控制模拟时间，衰减、粘度、涡旋和颜料流量随模拟时间更新；拖动推力仍由鼠标位移控制。加速时拆分子步，每步不超过 1/30 秒。
- 压力迭代：10–120 次，默认 60。越高投影精度越高，同时增加 GPU 开销。
- 分辨率：长边 128/256/384/512/1024/2048/4096 格，默认 256；短边随画布比例变化。更改即清空状态并释放、重建纹理。画笔半径、拖动力度、粘度和速度色阶以长边 256 格为基准，按实际网格换算。低分辨率仍会损失细节。4096 档在正方形画布上，仅模拟浮点纹理就约占 1.125 GiB 显存。

## 场景预设面板

右侧面板显示可滚动预设卡片，上方预览布局，下方编辑名称。默认“双圆”包含左右两个实心圆；新建预设为空场景。预设与选中状态保存在当前站点的 localStorage 中。面板收起后，移到右上角唤出按钮。窄屏默认收起。

本阶段仅实现预设管理和布局缩略图，不提供障碍物添加、画布展示或碰撞求解。相关界面与逻辑分别位于 presets.css、presets.js。

## 障碍物编辑与模拟

点击右侧“编辑预设”打开抽屉。添加圆形、三角形、长方形后，拖动形状移动，拖动四角缩放，拖动上方圆点旋转；选中后可删除。最多 64 个物体。勾号保存并应用，叉号或 Escape 放弃；编辑草稿不影响当前模拟。

预设使用带 schemaVersion: 2 的 JSON，保存在浏览器 localStorage。每个物体包含 type、x、y、width、height、rotation。x/y 是画布归一化中心坐标，原点左上；宽高以画布高度为单位，rotation 为弧度。旧圆形 r 数据自动迁移。暂无服务器、导入或导出。

选中或应用预设后，在模拟分辨率生成 R8 障碍物掩码上传 GPU。固体内部清零、固体相邻面的法向速度置零，压力只使用流体邻居；平流回溯遇固体停止，插值跳过固体采样。障碍物显示为浅灰色。网格近似边界，低分辨率下小物体会损失细节；这是视觉模拟，不是精密工程求解器。

## 障碍物显示与碰撞分离

障碍物外观由 obstacle-display.js 使用 SVG 在屏幕分辨率下抗锯齿绘制，与模拟共用同一组几何数据。该层不拦截鼠标操作，随预设应用及窗口尺寸更新。GPU 仍使用原来的 R8 网格掩码做碰撞，不增加流体网格分辨率。低分辨率时，流体与平滑视觉边缘仍可能存在约一个网格的偏差。
